# 🔌 API Testing

Esta pasta contém exemplos de testes de API utilizando diferentes ferramentas e frameworks.

## 📂 Conteúdo

### 1. Postman Collections
Coleções completas de testes de API com Postman, incluindo:
- Testes de endpoints REST
- Validação de schemas
- Testes de autenticação
- Testes de performance

### 2. REST Assured (Java)
Automação de testes de API com REST Assured.

### 3. Requests + Pytest (Python)
Testes de API usando Python com biblioteca Requests.

## 🎯 Tipos de Testes Incluídos

- **Testes Funcionais** - Validação de funcionalidades da API
- **Testes de Contrato** - Validação de schemas e estruturas
- **Testes de Segurança** - Autenticação, autorização e validação de dados
- **Testes de Performance** - Tempo de resposta e carga
- **Testes de Integração** - Fluxos completos entre APIs

## 🛠️ Ferramentas

- Postman / Newman
- REST Assured
- Python Requests
- HTTPie
- Insomnia

## 📊 Validações Realizadas

- ✅ Status codes
- ✅ Response times
- ✅ Response body structure
- ✅ Headers validation
- ✅ Schema validation (JSON Schema)
- ✅ Data integrity
- ✅ Authentication tokens
- ✅ Error handling
